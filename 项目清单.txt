🔬 核心技术点：

1. ARM64 寄存器
   - x29 (FP)：帧指针
   - x30 (LR)：链接寄存器
   - PC：程序计数器
   - SP：栈指针

2. 栈帧结构（16 字节）
   高地址 ↑
   ┌────────────────┐
   │ LR (x30)       │  ← FP + 8 (高地址)
   ├────────────────┤
   │ previous FP    │  ← FP + 0 (FP 指向这里，低地址)
   └────────────────┘
   低地址 ↓

3. Mach API
   - thread_suspend()：挂起线程
   - thread_get_state()：获取寄存器
   - thread_resume()：恢复线程

4. 符号化
   - dladdr()：运行时符号化
   - atos：离线符号化
